# Phase 1 — Core Platform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running local Synapse platform: a Bun + Hono API with durable jobs, scheduler, outbox events, leases, permissions, approvals, audit, health and recovery on SQLite, plus a Next.js skeleton dashboard and systemd unit files. Background work continues with the browser closed.

**Architecture:** Bun workspaces monorepo. `apps/api` is a Hono app on `Bun.serve` (127.0.0.1) that also runs background loops (scheduler tick, job workers, outbox dispatcher) in the same process. All core services are plain classes wired in a composition root (`container.ts`) and use synchronous Drizzle transactions over `bun:sqlite`. `apps/web` is a Next.js app that proxies `/api/*` and `/health/*` to the API.

**Tech Stack:** Bun 1.4.4 (runtime, workspaces, `bun test`), TypeScript 7.0, Hono 4.13 + `@hono/zod-validator` 0.9, Zod 4.6, Drizzle ORM 0.45 (`drizzle-orm/bun-sqlite`) + drizzle-kit 0.31, croner 11, Next.js 16.4 + React 19.3, Biome 2.6.

**Spec:** `CLAUDE.md`, `docs/architecture/{system-architecture,module-boundaries,database-design,event-system,integration-contracts,security-model,runtime-design}.md`, ADR-007, ADR-008, ADR-013, ADR-022, ADR-038, ADR-039. Phase scope from `pre-project-concept-document/concept.md` §21 Phase 1.

## Global Constraints

- Bun ≥ 1.4.4 for everything. Never invoke the system Node (v16). Run tools with `bun`, `bunx --bun`, `bun --bun`.
- TypeScript `strict: true`, `noUncheckedIndexedAccess: true`, ESM only.
- Internal IDs: `crypto.randomUUID()`. All stored times: ISO-8601 UTC strings from an injected `Clock`. Never call `new Date()` directly in core code.
- SQLite pragmas on every connection: `journal_mode=WAL`, `foreign_keys=ON`, `busy_timeout=5000`.
- API binds `127.0.0.1:7400`, web `127.0.0.1:7401`. Config must reject any non-loopback host.
- Default DB path: `$XDG_DATA_HOME/synapse/synapse.db` (fallback `~/.local/share/synapse/synapse.db`), overridable by `SYNAPSE_DB_PATH`.
- Job retries: `max_attempts = 3` (ADR-022), exponential backoff base 30 s, cap 30 min, jitter ±20 %, `retryAfter` overrides.
- Job statuses exactly: `PENDING`, `RUNNING`, `RETRY`, `COMPLETED`, `FAILED`, `NEEDS_ATTENTION`, `CANCELLED`.
- No Redis, no DI framework, no new runtime dependency beyond the stack list without an ADR.
- `apps/api/src/modules/**` must never import from `apps/api/src/integrations/**` or `apps/api/src/infrastructure/**` (boundary test enforces it).
- No secrets or message content in logs. Phase 1 makes no Claude, Slack or Jira calls.
- Every schema change ships with a generated migration; never edit an applied migration.

## Review Focus

1. **First run with no data directory**: the API must create the DB's parent directories, not crash. Test in Task 4.
2. **`SQLITE_BUSY` from concurrent writers** (worker, dispatcher and API on separate connections): writes must wait (busy_timeout), not throw. Test in Task 4.
3. **A job handler that never resolves**: it must be aborted at the job timeout and failed as `timeout`, freeing the worker. Test in Task 8.
4. **Laptop suspend / lost lease**: if a heartbeat finds the lease was taken or expired, the worker must abort that handler and not mark the job complete. Test in Task 8.
5. **Port already in use on start**: `main.ts` must exit non-zero with a clear message, so systemd restarts it, not hang. Test in Task 12.
