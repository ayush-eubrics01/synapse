# ADR-020: Group-Level People Memory Is Deferred
- **Status:** Accepted
- **Date:** 2026-11-05
- **Source:** concept.md §6.1

## Context
Group profiles (teams, channels) would add modeling and review complexity before individual profiles are proven useful.

## Decision
The initial scope has no group profiles and no group-level analysis. Messages in group DMs and channels are still collected for the inbox, urgency and commitments.

## Consequences
- Positive: smaller initial scope.
- Negative: team-level context isn't captured in People Memory yet.
- Follow-up: revisit after People Memory is in use.
